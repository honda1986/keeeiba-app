# keeeiba-app

中央・地方のその日の全レースから「買う価値のあるレース」(2強のレース)だけを選んで、◎○と買い目を出すアプリ。

アプリ: https://honda1986.github.io/keeeiba-app/ (GitHub Pages を main ブランチで有効にする)

## 流れ

1. 全レースから、強い2頭がいるレースだけを選ぶ(A / B)。1強・混戦・少頭数・新馬は見送り
2. 来ない馬の負け要因(距離・展開・枠・斤量・休み明け・クラス差・馬場・コース)で減点。重い減点が3つ重なった馬は消す
3. 残った馬から◎○を決める。距離延長の馬は軸にしない。◎○の弱点が同じ(両方逃げ・両方道悪苦手など)なら○を替え、替えられなければ見送り
4. 3連複は◎○2頭軸流し、3連単は◎⇄○の1・2着入れ替え
5. 馬連・ワイド◎-○で別の着順もカバーし、○-相手のワイドで◎が飛んだときに備える
6. 3頭目に人気薄(☆)を入れる

能力は過去5走の着差とクラスから作り、**人気・オッズは使わない**。オッズは評価ができたあとに
人気との食い違い(過剰人気? / 妙味)を見るだけ。アプリでもオッズは「最後に」開くまで隠している。

閾値(2強の差・消しの基準・点数)は `keiba_logic.py` の `TH` にまとめてある。
「収支・分析」で条件別の回収率、印ごとの3着内率、減点理由ごとの3着内率(負けパターン)を見て締めていく。

## ファイル

| ファイル | 中身 |
|---|---|
| `keiba_logic.py` | 評価・消し・◎○・判定・買い目・結果の照合(取得とは切り離した計算) |
| `keiba.py` | netkeiba から一覧・出馬表・馬柱・オッズ・結果を取り、予想と収支を保存する(`.github/workflows/keiba.yml`) |
| `test_keiba.py` | ロジックとパースの確認(`python -m unittest test_keiba`) |
| `keiba/index.html` | アプリ本体 |
| `keiba/data.json` / `keiba/days/YYYYMMDD.json` | いまの日 / 日別の予想と結果 |
| `keiba/history.json` | 収支・条件別の回収率・負けパターン |

発走を過ぎたレースの予想は書き換えない。収支は1点100円で、実際の払戻から計算する。
