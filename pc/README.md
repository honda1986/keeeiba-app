# PC でオッズを取る(タスクスケジューラ)

GitHub の時刻指定の実行は 3〜8時間遅れることがあり、開催日にオッズが古いままになる(2026-11-14 は朝の更新が昼まで始まらなかった)。
競輪(`honda1986/keirin` の `pc/`)と同じく、**ふだんのオッズは PC が取り、GitHub の更新は予備**という形にした。

```
Windows PC(C:\keiba)── タスクスケジューラ keiba_odds ─────────────────────
  毎日 08:40〜17:40  1分おきに1回ずつ(pc\task.bat → node pc\runner.js)
     ・10分おきに GitHub(main)の pc フォルダを取り込む(コードの更新)
     ・レースの一覧(発走時刻)は GitHub Pages の keiba/days/日付.json から(10分おき)。中央の開催が無い日は何もしない
     ・発走まで35分以内のレースの 単勝・ワイド・3連複 を netkeiba から取る(pc\odds.js。12分前からは毎回、それより前は3分おき)
     ・新しいオッズを odds-live ブランチへ送る(latest.json と snap\日付.json。いつも1コミットだけで、枝は膨らまない)
       │
       ▼
GitHub(honda1986/keeeiba-app の odds-live ブランチ)
  latest.json        … これからのレースのいちばん新しいオッズ。アプリが70秒おきに読んで、手元より新しければ入れ替える(どの端末でも)
  snap/日付.json      … その日の全レースの、発走前の最後のオッズ。GitHub の更新(keiba.py)が取り込んで記録に残す
                        (GitHub の更新が発走に間に合わなくても、発走前のオッズが残る)
```

PC が止まっていても、今までどおり GitHub の更新(遅れることがある)と Android アプリの「オッズ更新」は動く。切り替えの操作は要らない。

## 入れ方(これだけ)

スタートメニューで「**PowerShell**」を開いて、次の1行を貼って Enter:

```
irm https://raw.githubusercontent.com/honda1986/keeeiba-app/main/pc/install.ps1 | iex
```

あとは画面の言うとおりに(競輪のときと同じ):

1. 「このアプリがデバイスに変更を加えることを許可しますか」→ **はい**(新しい窓で続きます)
2. Git・Node.js は競輪で入れたものをそのまま使います。リポジトリは `C:\keiba\keeeiba-app` に **pc フォルダだけ**入ります(全部は数百MBあるため)
3. 「まだ送れません」と出たら、自動で開くトークンの画面で、**競輪・競艇で使っているトークンに keeeiba-app を足す**
   ([Edit] → Repository access に honda1986/keeeiba-app → Contents を Read and write → [Update])→ 窓に戻って Enter
4. 「できました」が出たら終わり。タスクの登録と試し運転まで済んでいます

何度貼っても壊れません。更新したいときも同じ1行を貼ればよい(ふだんは10分おきに自分で新しくなります)。
うまくいかなかったら、赤い字をそのまま貼って相談。

## 動いているかの確かめ方

| 見るところ | 何が分かるか |
|---|---|
| `C:\keiba\logs\odds_日付.log` | 1回ごとのログ(取ったレース・送った/送れなかった理由) |
| アプリのレースの画面の上「オッズ … · PC 12:34」 | PC が取ったオッズが入った時刻 |
| GitHub の odds-live ブランチの `latest.json`・`heartbeat.json` | PC が最後に送った時刻(新しいオッズが無くても5分おきに印を送る) |

## ファイル

| ファイル | 何をするか |
|---|---|
| `install.ps1` | 上の1行インストール(管理者に切り替え → Git/Node → pc フォルダ → 送れるか → 自己テスト → タスク登録) |
| `register_tasks.ps1` | タスク `keiba_odds` を登録する(毎日 08:40 から1分おき・9時間) |
| `task.bat` | タスクが呼ぶ。`node pc\runner.js` を1回動かす(`--dry` 送らない / `--force` 時間帯の外でも) |
| `runner.js` | ロック → pc フォルダの取り込み → `odds.js` → odds-live へ送る |
| `odds.js` | オッズを取って `latest.json`・`snap/日付.json` を作る。読み取りは `keiba.py` の `parse_*`・`trio_pair_sums` と同じ |
| `selftest.js` | 読み取りと時刻の計算の自己テスト(`node pc\selftest.js`) |

## 確かめたこと・確かめていないこと(2026-11-14)

- 確かめた: 自己テスト(6個)。にせのサーバーと手元の git で、取得 → `latest.json`・`snap/` → odds-live へ送る(1コミットのまま上書き)まで。
  アプリが `latest.json` を読んで入れ替えること。`keiba.py` が `snap/` を取り込むこと(テスト)
- **確かめていない**: 本物の netkeiba からの取得と、Windows での `install.ps1`・タスクの登録(作った場所から netkeiba と Windows に触れないため)。
  PowerShell の2本は競輪の `pc/` のものを元にしている。最初に入れるときは、出た字をそのまま見せてもらえれば直す
- **目的について**: 最初の目的は「割安ワイドを新しいオッズで選ぶ」だったが、同じ日の実戦で、発走の1分前のオッズで選んでも
  確定までに割安でなくなると分かった(README「市場が見落としている情報を探した」の 6)。PC で取る意味は、
  アプリのオッズ表示が新しくなることと、GitHub の更新が遅れても発走前のオッズが記録に残ること
